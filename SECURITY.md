# Security Policy

## Reporting a vulnerability

Please do not publish exploit details, secrets, tokens, private media, or personal data in a public issue.
Use GitHub's **Report a vulnerability** / private vulnerability reporting feature for this repository if it is enabled. If that feature is unavailable, contact the repository owner through their GitHub profile and share only the minimum details needed to investigate.

## Handling local media and credentials

Do not commit source footage, exported videos, API tokens, `.env` files, cookies, or private downloads. Keep local media under the ignored `input/` and `output/` paths. Never use browser cookies or account credentials to bypass private-post access restrictions.
