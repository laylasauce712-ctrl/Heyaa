# Heyaa optimization roadmap

## Current implemented state (feature branch)

- Output settings are read from `params.json`; supported output is 1080x1920 (9:16), configurable 24–60 FPS, 8–60 seconds, speed 1.0–1.35x, and a frame-quantized final freeze. Unsupported types/ranges fail fast.
- **Optional AI detail restoration:** if `video_settings.ai_upscale_enabled` is true, each selected clip's source frames are extracted losslessly, enhanced by the external Real-ESRGAN ncnn-vulkan model, then returned to the normal crop/edit pipeline. This is model-generated enhancement, not proof of recovered original detail. AI mode fails fast if the binary or model files are missing; it does not silently pretend Lanczos is AI upscaling. Install the official pinned Linux build with `bash scripts/install_realesrgan_linux.sh`, verify the default Vulkan device is hardware-backed, then enable AI Restore in the Studio (saved to ignored `params.local.json`). The feature toggle is explicit; the tracked fresh-checkout profile leaves it off so a standard render works without separately ignored binary/model assets. Install the executable and model files, confirm a hardware-backed default Vulkan device, then enable it in the Studio when ready.
- **Framing and face location:** `edit_settings.layout_mode="fill"` fills the 9:16 canvas by cropping. When OpenCV and its frontal-face Haar cascade are available, face-location observations take priority for a smoothed crop path; the HOG person detector fills face-detection gaps and remains the fallback when no stable face track is found. If no stable track exists, centered cropping remains available. `layout_mode="blur_fit"` preserves the entire source frame in the foreground and fills the unused portrait canvas with a blurred background. This is face-location tracking only—not face recognition, biometric identification or identity verification. The setting `edit_settings.face_detection_enabled` defaults to true.
- Mirror is an explicit `edit_settings.mirror_enabled` boolean; it no longer alternates on a per-clip rule. A horizontal flip can reverse visible text.
- The validated, frame-based EDL now drives source ranges, clip durations, freeze placement and the supported full-timeline audio segment. The renderer rejects unsupported crop rectangles or unsupported audio schedules instead of silently ignoring them.
- The synthetic CI render checks EDL continuity, exact decoded frame count, output dimensions/FPS/duration, audio and full-file decoding.
- Deterministic Python agents run real settings, media, beat, reference, framing, opening-scene-change, planning, niche-evidence, Inspector and Render Critic stages. Hook Analyst supplies an opening cut-cadence proxy, and Niche Analyst supplies a low-confidence craft proxy composite only when required inputs exist; neither claims semantic hook understanding or predicts virality. A structured evidence-linked review conference is stored in the report and printed in the terminal; it is rule-based cross-review, not independent LLM-to-LLM conversation.
- **Audio transition detection:** the lightweight FFmpeg low-band RMS/onset path estimates a periodic beat grid. The optional internal drop hold now requires a measured onset plus sustained low-frequency energy rise and minimum confidence; an isolated transient is not enough. It is an audio transition proxy, not semantic music understanding.
- **Visual risk QA:** Render Critic samples frames at low resolution and measures blur, very dark sample share and long unintended still intervals, in addition to black intervals and audio levels. The intentional terminal 2-second freeze is excluded from the still-frame warning. The checker does not score composition, aesthetics or semantic subject visibility.
- Missing evidence remains visible. Scene-change counts are not semantic scene understanding; beat timing and drop candidates are low-band energy proxies; face detection reports a location only; the hook agent does not assign semantic hook strength; niche craft scoring remains unavailable until all required metrics are measured.
- Latest verified CI runs pass the current unit-test suite and the synthetic end-to-end render smoke test. Keep test counts in CI output rather than hard-coding them here, so this status note does not become stale. The integration render verifies structural correctness for the normal 20-second 1080x1920, 60-FPS output (1,200 decoded frames), audio, continuous EDL and exact 2-second freeze using generated fixtures. It disables the optional external Real-ESRGAN binary/model path in CI; unit tests cover its fail-fast contract. This does not prove visual quality on real user footage.
- No real user footage has been visually reviewed in this repository's CI.

## Remaining stages

1. **Real-footage visual QA:** test framing, subject visibility, mirrored text, skull scale/position, flash timing, drop-freeze placement, and audio level using the user's own sample clips.
2. **Critic improvements:** add crop/subject-visibility measurements and calibrated representative-frame tests. Current Render Critic now samples blur, darkness and unintended still frames, but does not judge aesthetics/composition or run an automatic retry.
3. **Beat timing:** validate the sustained low-band transition score on a representative music set, including short intros, gradual builds and loop boundaries. Keep even pacing and omit internal holds when confidence is low.
4. **Stronger subject tracking:** test face-location/HOG consistency across camera cuts, side profiles, occlusion and multiple visible people. Current Haar face boxes and HOG detections are short-lived framing observations; they do not recognize identity or understand actions.
5. **Agent Room/UI:** the existing local Studio now presents real structured events in a chat-style feed, with recorded speaker/recipient information, findings, recommendations, compact evidence and an explicit active-process indicator. It deliberately shows an indeterminate activity sweep rather than inventing a percentage. Future work: enrich stage-level progress and improve the presentation of large evidence payloads without simulating messages.
6. **True LLM collaboration and trend research:** add explicit providers, prompts, cost/timeout controls and evidence citations before describing the system as independent AI agents. Do not fabricate inter-agent chat or promise virality.
7. **Termux performance:** benchmark render time, memory and storage on a real Android device before claiming performance optimization.

## Acceptance gates

- Unit tests and the synthetic FFmpeg smoke test pass on the current branch head.
- One validated settings object feeds settings QA, EDL planning and FFmpeg rendering without silent clamping.
- Unsupported timeline/crop/audio combinations block export before expensive rendering.
- The Director reports its decision, evidence and blockers; Export Storage does not replace the last known-good file unless all required technical gates pass.
- A real-footage review is recorded separately from synthetic CI evidence.
- Do not merge to `main` until the project owner reviews the evidence and explicitly approves.
